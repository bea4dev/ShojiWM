# ShojiWM の既定の設定（MD3E）

[ShojiWM](https://github.com/bea4dev/ShojiWM) の既定の設定です。インストールすると `~/.config/shojiwm` に置かれます。シェルの [shoji-bar-4](https://github.com/bea4dev/shoji-bar-4) と組み合わせて、Material 3 Expressive のデスクトップにします。

ウィンドウの管理（タイル、ワークスペース、ジェスチャー、スナップ、Super+Tab）は、以前の既定の設定と同じです。違うのは見た目と動きです。

## 見た目

- **ウィンドウの枠**（`src/md3e/decoration.tsx`）
  - 角丸は 16px です。
  - どのウィンドウにも、クライアントの外側に 1.5px の枠線を引きます（クライアントに隠れないよう、枠の一部として描きます）。フォーカスのあるウィンドウは白、ほかは灰色です（フォーカスが移ると、ばねで色が移ります）。自分で枠を描くクライアントにも引きます。
  - フォーカスが移ると、枠線が外側へ一瞬太くなって戻ります（`BORDER_SWELL` で太さと時間を変えられます）。
  - 影はフォーカスがあると高く、ないと低くなります。フォーカスが移ると、ばねで移り変わります。
  - タイトルバーは高さ 36px で、スキームの surface の色です。フォーカスがないと、一段沈んだ色になります。
- **ボタン**（最小化・最大化・閉じる、`src/md3e/shaders/caption-button.frag`）
  - ポインタが乗ると、真ん中から泡が広がります。少し行き過ぎて戻ります。
  - 押すと、円から角丸の四角に変わり、少し横に伸びます。
  - 閉じるボタンは error の色になり、× が四分の一回ります。
  - 最大化のアイコンは、ウィンドウの状態に合わせて「元に戻す」のアイコンに形を変えます。
- **自分で枠を描くクライアント**（GTK 4、Chrome など）：枠はそのままにして、角丸と影と線だけを足します。
- **ドラッグ＆ドロップ**（`src/drag-and-drop.tsx`）
  - アプリの画像を、背景をぼかしたスキームの surface のカードに載せ、下に何を運んでいるか（Text、File、Image、Link、Data）のピルを付けます。
  - カードの角に、ドロップしたらどうなるかのバッジが出ます：+ コピー（primary）、→ 移動（tertiary container）、? 確認（secondary）、受け取らないウィンドウの上では ×（error）。バッジはばねで飛び出し、動作が変わるたびにもう一度弾みます。
  - 受け取るウィンドウの上では、カードが少し大きく丸くなり、primary のリングが付きます。受け取らないウィンドウの上では、首を振るように小さく揺れます。
  - ドラッグを始めるとカードがポインタから飛び出し、受け取られると相手に沈み込み、誰も受け取らないと元の場所へ（少し行き過ぎて）飛んで戻り、消えます。
- **色**：shoji-bar-4 から届くスキームを使います（下を参照）。届くまでは Material 3 の基準のダークスキームです。変わるときは全部の色が一緒に移ります。

## 動き

ウィンドウのアニメーションは 0.25 秒（開く・閉じるは 0.35 秒）で、次の 2 本の曲線を使います（`src/md3e/motion.ts`）。

- `cubic-bezier(0.1, 0.9, 0.2, 1)`：すばやく動き出し、ゆっくり着地します。
- `cubic-bezier(0.1, 1.1, 0.1, 1.1)`：同じ動きで、少し行き過ぎて戻ります。

| 動き | 内容 |
|---|---|
| 開く | 下から上がりながら、少し小さいところから大きくなります。どちらも少し行き過ぎて戻ります。同時にフェードインします。 |
| 閉じる | 少し縮みながら消えます。 |
| 最小化 | 縮みながらドックの方へ沈みます。戻るときは、少し行き過ぎて浮かび上がります。 |
| 最大化・スナップ | 行き過ぎない方の曲線です。 |

タイルとワークスペースの切り替えは、以前の既定の設定と同じ 0.5 秒のままです。ボタンやフォーカスの小さな動きは、Material 3 Expressive のばねで動きます。

## ぼかし

- **ウィンドウの後ろ**：ぼかした背景を敷きます。透けるクライアント（kitty の `background_opacity` など）から見えます。タイトルバーは不透明です（`TITLE_BAR_ALPHA` を 1 より小さくすると透けます）。
- **シェルの後ろ**：shoji-bar-4 のレイヤーとポップアップの後ろもぼかします。ぼかしが見えるのは、半透明に描いたところだけです。壁紙のレイヤーは除きます。

## shoji-bar-4 との連携

- **シェル**：ShojiWM が `~/.config/shoji-bar-4/target/release/shoji-bar-4` を起動します。
- **色**：shoji-bar-4 が、IPC のソケット（`$XDG_RUNTIME_DIR/shojiwm-$WAYLAND_DISPLAY.sock`）にスキームを `theme.set` で送ります。
  - 送るのは、起動したとき、つながり直したとき（設定のリロードを含む）、スキームが変わったときです。
  - クイック設定で色やライト／ダークを変えると、ウィンドウの枠も一緒に変わります。

### キー

| キー | 動作 |
|---|---|
| `Super`（単押し）／`Super+A` | ランチャー |
| `Super+N` | クイック設定 |
| `Super+C` | カレンダー |
| `Super+V` | クリップボードの履歴 |
| `Super+L` | 画面のロック |
| `Super+Tab` | ウィンドウの一覧（flip 3D。`src/index.tsx` の `WINDOW_SWITCHER_STYLE` を `"grid"` にすると、並べた一覧になります） |

ほかのキーは、以前の既定の設定と同じです（[既定の設定](https://github.com/bea4dev/ShojiWM/blob/main/docs/docs/configuration/default-config.md)を参照）。

## 使い方

ShojiWM の既定の場所（`~/.config/shojiwm`）に置けば、`--config` なしで起動できます。ディスプレイマネージャーの ShojiWM セッションでも、この設定で始まります。

```sh
shoji_wm --tty
```

## 試す

入れ子の ShojiWM で、いまのセッションと切り離して試せます。いまのセッションのソケットや環境には触れません。

```sh
dev/preview.sh                 # 入れ子の ShojiWM を起動する
dev/preview.sh run kwrite      # その中でアプリを起動する
dev/preview.sh theme light     # shoji-bar-4 のようにスキームを送る（light / dark / JSON のファイル）
dev/preview.sh reload          # 設定を読み直す
```

`dev/preview-state.ts` で、出力の倍率やボタンの見た目の固定（`button: "close"`、`"maximize:pressed"`）を変えられます。
